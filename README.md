## 🚀 Getting Started

### Prerequisites

You need a C++ compiler installed on your system (such as `g++` via GCC or Clang).

### Compilation and Execution

To compile and run any of the programs, use your terminal:

```bash
# Compile the file
g++ filename.cpp -o program

# Run the executable
./program
```
